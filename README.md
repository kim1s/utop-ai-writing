# UTOP AI Writing (프로토타입)

AI 서·논술형 평가 서비스의 **교사용 화면** 프론트엔드 프로토타입입니다.
DB·API 없이 동작하며, 모든 데이터는 브라우저 localStorage(zustand persist)에 저장됩니다.

## 실행
```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 프로덕션 빌드 확인
```

## 기술 스택
Vite · React 19 · TypeScript · React Router · Tailwind CSS v4 · Zustand · xlsx(엑셀 입출력) · pdf-lib(PDF 쪽수 읽기)

## 화면 / 기능
수업(반) 개념 없이 **평가**가 최상위 단위입니다. 평가에는 두 가지 이름이 있습니다.
- **평가명**: 선생님이 평가를 구분하기 위한 이름 (학생에게 비노출)
- **과제명**: 학생에게 보이는 이름 (답안지·채점 결과 리포트에 사용)

| 영역 | 경로 | 내용 |
|---|---|---|
| 나의 평가 (홈) | `/` | 평가 목록(학기·교과 필터), 평가 만들기(새로 만들기/복사/평가 자료실), 학생 관리 진입 |
| 평가 만들기 | `/evals/new` | 기본 정보(평가명·과제명·학년도/학기·교과) + 성취기준·채점기준·점수 계산·결시자 처리 |
| 평가 대상 | `/evals/:id/targets` | 학급 단위/개별 학생 추가·제외(이동형 UI) |
| 평가 설계 | `/evals/:id/design` | 설계 수정 |
| 과제물 관리 | `/evals/:id/submissions` | 제출 현황, 학생별 파일 추가/제거, 학급 PDF 분할 업로드 |
| AI 채점 | `/evals/:id/grading` | AI 채점 진행 시뮬레이션, 결과 상세, 학생 채점 상세, 결과 출력(인쇄) |
| 평가 리포트 | `/evals/:id/report` | 평가 요약, 학생별 표, 엑셀 다운로드, 학생 리포트 |
| 내 정보 / 학교 정보 | `/my-info`, `/school` | 담당 교과, 선생님 목록, 학생 개별·엑셀 일괄 등록 |
| 평가 자료실 / 고객센터 | `/library`, `/support` | 공개 평가 둘러보기·가져오기, 공지/FAQ/1:1 문의 |

## 프로토타입 동작 메모
- 푸터의 **프로토타입 도구**로 데모 데이터 복원 / 빈 상태 초기화를 할 수 있습니다. (빈 상태에서 처음부터 흐름 체험 가능)
- AI 채점은 `src/lib/grading.ts`의 `simulateAiScore`가 만든 결정론적 가짜 결과입니다. 실제 API를 붙일 때 이 함수와 `store.ts`의 `tickGrading`을 교체하면 됩니다.
- 업로드한 PDF 원본은 새로고침하면 사라지며(메타데이터만 저장), 이 경우 가상의 샘플 답안지가 표시됩니다.
- 실서비스 연동 시: `src/lib/store.ts`의 액션들이 API 호출 지점입니다.
